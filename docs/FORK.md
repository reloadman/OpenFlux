# Что добавлено в этом форке

Апстрим: [p1neappleXpress/OpenFlux](https://github.com/p1neappleXpress/OpenFlux).
Логика туннеля и транспортов не менялась — добавлены клиент под Android, обвязка для
безопасного запуска exit node и документация по граблям, найденным на практике.

## Android-приложение

`android/` — приложение с кнопкой включения, статусом и лентой лога. Поднимает
`VpnService`, так что весь трафик устройства идёт в туннель без ручной настройки прокси.
В апстриме Android-проекта нет вовсе: `build_android.sh` собирает только консольный
бинарь, который надо запускать из Termux.

`mobile/` — Go-обёртка над [tun2socks](https://github.com/xjasonlyu/tun2socks),
собирается в AAR через `gomobile`. Связывает дескриптор tun-интерфейса от `VpnService`
с локальным SOCKS5, который поднимает клиент.

Подробности сборки и подводные камни — [docs/ANDROID.md](ANDROID.md).

## Запуск exit node в изоляции

`deploy/` — скрипт network namespace и systemd-юниты. Нужны потому, что exit node
требует правила `iptables -A OUTPUT -p tcp --tcp-flags RST RST -j DROP`, а оно
глобальное и ломает соседние сетевые службы на той же машине. В namespace правило
действует только для туннеля.

Подробности — [docs/DEPLOY.md](DEPLOY.md).

## Мелочи

* `build_apk.sh` — собирает APK целиком: бинарь клиента, AAR с tun2socks и само
  приложение. Проверен на чистой сборке.
* `build_android_linux.sh` — сборка Android-бинаря на Linux. В штатном
  `build_android.sh` путь к toolchain зашит под macOS (`darwin-x86_64`), на Linux он не
  отрабатывает.

## Известные ограничения

* **UDP не проксируется.** SOCKS5-сервер принимает только `CONNECT`, поэтому DNS
  (работает по UDP) через туннель не проходит. Android-клиент обходит это, выводя
  DNS-трафик из туннеля отдельными маршрутами — ценой того, что запросы видны провайдеру.
* **Транспорт `yandex` зависит от вида ссылки на документ.** Годится ссылка
  «поделиться файлом» (`/i/<id>`); ссылка на редактор (`/edit/d/<id>`) отдаёт новый
  WOPI-редактор, в котором нет полей, нужных транспорту.
* Приложение собрано и проверено только для `arm64-v8a`.
